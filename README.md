# Sheffield Cleaning Services

A responsive three-page cleaning services website created as a junior web development portfolio project.

## Project Overview

This website presents a fictional cleaning service based in Sheffield. It includes information about cleaning services, a contact form, responsive layouts and basic SEO practices.

## Features

- Responsive design for desktop and mobile
- Three-page website
- Home, Services and Contact pages
- Responsive navigation
- Cleaning service cards
- Contact enquiry form
- JavaScript form interaction
- Form success message
- Image with descriptive alt text
- Semantic HTML structure
- Page-specific title and meta description
- Basic accessibility improvements
- Git and GitHub version control

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Pages

- `index.html` — Home page
- `services.html` — Cleaning services
- `contact.html` — Contact and enquiry form

## What I Learned

Through this project, I practised building a responsive website from scratch, organising multiple HTML pages, styling layouts with CSS and Flexbox, adding JavaScript interactions, applying basic SEO principles, considering accessibility, and using Git and GitHub for version control.
